# Stem to MIDI

Sunoなどで分離したWAVステムを、編集可能なMIDIへ変換するためのローカルツールです。

最初のバージョンは **Tempo Lab** に限定しています。WAVからテンポと拍位置を解析し、音源を聴きながら固定テンポのBPMと先頭拍位置を調整して、後工程で再利用できるJSONを保存します。

## 現在できること

- WAVファイルの読み込み
- BPMと拍位置の自動検出
- 体感テンポとMIDI量子化用の内部グリッドを分けて調整
- 波形上への検出拍・体感拍・内部グリッド表示
- BPMの手入力、半分・倍テンポ補正
- 先頭拍位置の10ms／50ms単位調整
- 先頭拍誤差と検出終了後の余白表示
- 体感拍または内部グリッドを選んだクリック付きプレビュー
- 解析結果、体感拍、内部グリッドのJSON出力
- 保存済みtempo.jsonを読み込み、作業状態を復元
- Version 1 JSONの自動移行とVersion 2 JSONの再読み込み
- SHA-256、またはファイル名と長さによるWAV照合

現時点では固定テンポ向けです。Sunoの「Follow tempo changes」に対応する可変テンポマップ編集とAudio-to-MIDI変換は次段階です。

## JSONから作業を再開

WAVを選択した後、「保存済みtempo.jsonから作業を再開」を開いてJSONを選択します。

読み込んだJSONから、次の編集状態を復元します。

- 体感テンポ
- 内部グリッド倍率
- 先頭拍位置

拍時刻の配列はJSONから直接復元せず、上記の設定と現在のWAVの長さから再生成します。これにより、設定値と保存済み拍配列が食い違っていてもグリッドを一貫した状態に保てます。

元WAVのSHA-256が一致しない場合は警告し、確認チェックを入れるまで設定を適用しません。SHA-256がないJSONでは、ファイル名と音源の長さで簡易照合します。

## 体感テンポと内部グリッド

ハーフタイムに感じる曲では、体感テンポを72 BPM、内部グリッドを144 BPMのように分けられます。

- **体感テンポ**: 曲を聴いたときの大きな拍
- **内部グリッド**: ベースの8分音符や16分音符を量子化するための細かい拍

`÷2`と`×2`は、内部グリッドをなるべく維持しながら体感テンポを変更します。内部グリッド倍率は`×1`または`×2`から選択できます。

## セットアップ

Python 3.11以上を使用します。

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -e ".[dev]"
```

## 起動

```bash
streamlit run app.py
```

ブラウザでWAVを選択し、クリック付きプレビューを聴きながらBPMと先頭拍位置を調整します。

## データ管理

音源や生成物はGitへコミットしません。ローカルでは次のような構成を推奨します。

```text
workspace/
├─ input/
│  └─ song-name/
│     ├─ fixed/
│     └─ follow/
└─ output/
```
